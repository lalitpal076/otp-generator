# OTP Generator

A simple React app to generate secure 6-digit OTPs with a countdown timer.
---
[![Visit App](https://img.shields.io/badge/Visit-App-orange)]([https://link](https://otp-generator-neon.vercel.app/))
## Features
- Generates random 6-digit OTP
- OTP expires automatically after 5 seconds
- Countdown timer displayed on screen
- Button disabled until OTP expires
